# 図書館予約アプリ

1. アクティビティ
2. タスク
3. ウォーキングスケルトン
4. リマインド対応(v1.0)
5. 専用アプリの追加(v2.0)

- 探す #会員 #司書
  - 本を検索する
    - [ ] Webの検索ページを開く
      - v 専用アプリを開く
    - 書名を検索して、検索ボタンを押す
      - 作者名でも検索できる
        - 専用アプリでバーコードを読み取る
  - 司書に探してもらう
    - [x] Webで依頼フォームを開く
- 借りる #会員 #司書
  - 貸出中の本を予約する
    - Webで本を選んで予約ボタンを押す
